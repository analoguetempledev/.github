# Analogue

We build websites, internal tools and automations for businesses that need one thing to work properly.

Analogue is a small independent build team based in Portimão, Portugal. Most of our work is one working tool for one real workflow, in production within weeks — not a platform, not a rewrite.

## What we build

- Marketing sites that load fast and stay maintainable
- Internal tools that replace a spreadsheet and a group chat
- Automations that remove a repeated manual step
- AI features where they earn their place

## How we work

The first call is free, and we spend it on your actual workflow rather than a feature list. If it makes sense to continue, we scope the work in phases and agree a fixed price per phase — no hourly rate, no open-ended estimate.

Ongoing work runs as a monthly retainer.
